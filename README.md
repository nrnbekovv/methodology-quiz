# Methodology Quiz
Static website, no login or server required. Open index.html locally or upload the files to a public GitHub repository. Settings → Pages → Deploy from a branch → main → /(root) → Save.
300 questions, 6 parts of 50. Source PDF places the apparent correct answer first (A); no separate answer key was supplied. The website shuffles answer choices while retaining that inferred key. Progress is stored in localStorage on the current browser. Retry mistakes replaces the saved attempt for that part. No external dependencies.
